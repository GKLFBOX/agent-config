# 外部記憶ルール — Tasks

## タスクの持ち方

- タスクの正本は発生した文脈のノート（主に `Projects` の各ノートの Todo セクション）。`- [ ]` で書く。
- 完了したタスクはチェックで残さず削除する（履歴は Handoff と `Decisions` が担う）。
- Todo項目は動詞で終わる行動として書く。未確認・未決定の事項も「〜を検証する」「〜を判断する」の形にする（core.md「Projectノート構成」）。
- Obsidian コミュニティプラグイン（Tasks 等）は使わない。横断は組み込み検索の表示で行い、タスク行を別ノートへ複製しない。
- タスク行に `#todo` などの集約用記法を付けない。対象は置き場所（`Projects` 配下）で決める。
- 非紐付けの開発タスクは orphan Todo ノート `Projects/雑務.md` に置く。
- 未分類のタスクは `Inbox` に記載する。

## 分類別一覧

- Project一覧は `Projects` フォルダを開く。
- あるProjectのDecision / Knowledge / Handoffは、Projectノートのバックリンクで確認する。
- 未処理Inboxは `Inbox` フォルダを開く。
- 個別Todoは各Projectノートを開いて確認する。未完了タスクを横断して見るときはルート`Todo.md`を開く。
- `Todo.md`の検索結果はチェックできない。完了は行をクリックして元のノートで行う。
- 優先順位変更・延期はユーザー承認後に反映する。

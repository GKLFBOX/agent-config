# External Memory: Inbox

規約は正本に従う: `../external-memory-rules/core.md`（分類・昇格の判断を含む）。

1. `Inbox` 内のMarkdownファイルを一覧化する。
2. 各項目について、Project / Knowledge / Decision / Daily / Vault外archive の分類案を作る。タスクは発生した文脈のノートへ残す。
3. 移動・統合・Archive化の一覧をユーザーへ提示する。
4. ユーザー承認後に変更する。
5. 判断できない項目はInboxへ残す。
6. 変更結果と残件を報告する。
